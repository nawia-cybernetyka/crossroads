Flash test

Runs the real src/ code — ihex.js and halfkay.js, not a copy — to verify the three constants the spike could not: block size 1024, data offset 64, and the erase delay.

This overwrites the firmware on the connected Teensy.

That is safe and reversible: HalfKay lives on a separate bootloader chip (an MKL02), so no firmware you flash can prevent the board from re-entering the bootloader. Hold the Program button and it always comes back.

  1. Put the board in bootloader mode (hold Program while plugging in).
  2. Parse only first — validates the .hex with no writes.
  3. Connect, then Flash.
