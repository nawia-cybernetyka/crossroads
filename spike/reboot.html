Soft reboot spike — 134 baud

The Teensy 4 core reboots into the HalfKay bootloader when the host opens its USB serial port at 134 baud (that is how the Teensy Loader does it). This page asks one question: can a web page do that with Web Serial, and then claim the bootloader over WebHID? If yes, most firmware updates need no recessed button.

Chrome or Edge only. Pedal running normal firmware, nothing held.

  1. Identify — pick the pedal's serial port, read its ? identity line. Proves the port is the pedal.
  2. Reboot — re-open the same port at 134 baud. The board should drop off the bus within ~100 ms and come back as HalfKay.
  3. Claim — request the HalfKay HID device. A second permission prompt here is acceptable; failure to find it is not.
